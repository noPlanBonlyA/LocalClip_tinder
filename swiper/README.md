# Clip Tinder (свайпер)

Сайт «как тиндер» для клипов из Google Диска. Открывается на компе и на телефоне.

| Действие | Google Диск | CRM |
| --- | --- | --- |
| Клип появился в `to sort/<стример>/` | — | тикет в **Бэклоге**: название `клип (стример)`, ссылка на файл, размер, длительность, история |
| **Свайп вправо** / ✓ / `→` | LocalClip монтирует **сокращённо** (вырезает паузы и слова-паразиты) → результат в `montage/<стример>/`, исходник в `montage/<стример>/исходники/` | готовые видео добавляются в тикет, тикет → **Уникализировано**; в заметках ссылки и хук-заголовок |
| **⏱ целиком** / `Shift+→` | то же, но по полному хронометражу, файл `имя (целиком).mp4` | то же |
| **Свайп влево** / ✕ / `←` | файл → `trash/<стример>/` | тикет остаётся в Бэклоге, в названии `[УДАЛИТЬ]` |
| **Свайп вверх** / 🤔 / `↑` | файл остаётся в `to sort` | тикет остаётся в Бэклоге, клип на вкладке «Подумать» |

После каждого свайпа несколько секунд висит кнопка **«Отменить»**. Удалённый клип можно вернуть и позже, во вкладке «Корзина»; клип в очереди на монтаж отменяется во вкладке «Монтаж». Вкладка «Монтаж» показывает прогресс, ошибки (кнопка «Повторить») и ссылки на готовые видео.

Стример берётся из имени подпапки: `to sort/sasavot/минус-4.mp4` → стример `sasavot`. Папки `montage`, `trash` и подпапки стримеров создаются сами.

## Как это устроено

```
телефон/комп ──https──▶ Cloudflare Tunnel ──▶ свайпер (Node, :3200)  ── на том же ПК, что и LocalClip
                                                 │  Google Drive API (OAuth)
                                                 │  CRM API (/api/tickets)
                                                 └▶ LocalClip API (:8000): /upload → /tasks → /clips/…/file
```

Свайпер работает на Windows-ПК с LocalClip, потому что монтаж идёт на его видеокарте. Монтаж выполняется по одному клипу за раз. Если ПК или свайпер перезапустились, незаконченный монтаж продолжится. Видео на телефон идёт напрямую с Google Диска через сервер свайпера, с перемоткой. Состояние хранится в `swiper/data/state.json`.

Короткие клипы (до `WHOLE_CLIP_MAX_SECONDS` = 120 с, задаётся в `.env` LocalClip) LocalClip монтирует **целиком** одним роликом: 9:16, фейскам, субтитры, хук-заголовок. Более длинные файлы он нарезает AI как обычно, и тогда в `montage` попадёт несколько видео: `имя (1).mp4`, `имя (2).mp4`…

## Установка (один раз)

Нужен уже установленный и хотя бы раз открытый LocalClip: свайпер работает от его встроенного пользователя.

### 1. Google Диск

1. https://console.cloud.google.com → создайте проект → **APIs & Services → Library → Google Drive API → Enable**.
2. **OAuth consent screen**: тип External, впишите себя в Test users. Затем нажмите **Publish app** (статус *In production*). Иначе Google отзывает токен через 7 дней. Проверка приложения Google для личного использования не нужна: при входе будет предупреждение «приложение не проверено», нажмите «Продолжить».
3. **Credentials → Create credentials → OAuth client ID → Desktop app**. Скопируйте Client ID и Client secret в `swiper/.env` (`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`).
4. В папке `swiper` выполните `npm install`, затем `npm run google-auth`. Откройте ссылку и войдите **аккаунтом-владельцем папки** (или аккаунтом с правом редактирования). Скрипт сам допишет `GOOGLE_REFRESH_TOKEN` в `.env`.

`DRIVE_ROOT_FOLDER_ID` — id папки, внутри которой лежат `to sort`, `montage` и `trash`. По умолчанию это папка из ссылки `1TUTNzuNI8n9tv5NlN72EKkdZYHuP6GsH`.

> Сервисный аккаунт Google не подойдёт: он не может загружать файлы в обычный «Мой диск» (у него нет квоты), поэтому используется OAuth.

### 2. CRM

В разделе **Команда** создайте пользователя для свайпера, например `swiper`. Впишите `CRM_LOGIN` и `CRM_PASSWORD` в `swiper/.env`. `CRM_API_URL` — адрес API на Railway (`https://api-production-34217a49.up.railway.app`), а не сайта на Vercel. Менять саму CRM не нужно.

Без `CRM_*` свайпер работает и без CRM, просто не создаёт тикеты.

### 3. Пароль сайта

`APP_PASSWORD` в `swiper/.env` — общий пароль команды. Сайт доступен из интернета, поэтому пароль обязателен. При входе каждый указывает имя: оно пишется в историю тикета («👍 на монтаж (Андрей)»).

### 4. Запуск

Дважды кликните **`Swiper.cmd`** в папке LocalClip (LocalClip при этом должен быть запущен). Скрипт:

- при первом запуске создаст `swiper\.env` и откроет его в блокноте;
- установит Node и `cloudflared`, если их нет;
- запустит свайпер и туннель. В окне появится ссылка `https://…trycloudflare.com` — откройте её на телефоне и добавьте на главный экран.

Быстрый туннель меняет адрес при каждом запуске. Для постоянного адреса создайте бесплатный туннель в Cloudflare Zero Trust (Networks → Tunnels, сервис `http://127.0.0.1:3200`) и впишите его токен в `CLOUDFLARE_TUNNEL_TOKEN`.

Без туннеля, в одной Wi-Fi сети: `HOST=0.0.0.0` в `swiper/.env`, затем откройте `http://<ip-ПК>:3200`.

## Разработка

```bash
cd swiper
npm install
npm test          # e2e на фейковых Google Drive / CRM / LocalClip
npm start
```

Код:

- `src/swiper.js` — логика: синхронизация, свайпы, отмена, очередь монтажа, тикеты;
- `src/drive.js`, `src/crm.js`, `src/localclip.js` — клиенты API;
- `src/server.js` — HTTP, вход, прокси видео;
- `public/` — интерфейс без сборки.

## Что не проверялось вживую

Всё проверено автотестами против фейковых серверов, которые повторяют форматы ответов Google Drive v3, CRM и LocalClip, а интерфейс — в браузере на телефонном и десктопном размере. **С настоящим Google Диском, CRM и LocalClip на Windows связка не запускалась.** Первый прогон: положите один короткий клип в `to sort/<стример>/`, свайпните вправо и проверьте, что видео появилось в `montage/<стример>/`, а тикет переехал в «Уникализировано» с прикреплённым видео.
